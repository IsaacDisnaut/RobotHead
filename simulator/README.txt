โปรแกรมจำลองหุ่นยนต์ "น้องมะลิ" (Nong Mali Robot Simulator)
==============================================================

วิธีเปิด
--------
ดับเบิลคลิก  "เปิดโปรแกรมจำลองหุ่น.bat"
(หรือพิมพ์  python robot_sim_server.py  ในโฟลเดอร์นี้)
เบราว์เซอร์จะเปิด http://127.0.0.1:8765 ขึ้นมาเอง -> กด "คลิกเพื่อเริ่มจำลอง"
ปิดโปรแกรม: กด Ctrl+C ที่หน้าต่างดำ หรือปิดหน้าต่างนั้นไปเลย

สิ่งที่จำลอง (อิงจากไฟล์ในโฟลเดอร์ my_robot)
---------------------------------------------
- โมเดล 3D: ลำตัวและโครงหัวจากไฟล์ STL จริงใน 3D_Print + หน้ากาก/ตา/ปาก/เซอร์โวคอ
- ESP32-S3 (Esp32 s3.txt): คำสั่ง Serial  T,pan,tilt,eyeX,eyeY / NOD / TILT / THINK / I
  ความเร็วเซอร์โว (0.14), ขอบเขตมุม Pan 30-150 Tilt 50-130, หมดเวลา 2.5 วิ, ส่ายหัวเองตอนว่าง,
  กะพริบตา, กลอกตา, ม่านตาขยาย-หด บนจอ GC9A01 ทั้ง 2 จอ
- Jawduino (Arduino Nano + KA2284): ปากขยับตามระดับเสียงพูด 0-3 ดวง (15°-60°)
- robot_brain.py: ติดตามใบหน้า, สถานะ IDLE/NOTICED/CHATTING, ทักทายเมื่อเดินเข้ามาใกล้
  (face_ratio >= 0.24), คำทักทายตามช่วงเวลา, คำบอกลา, เงียบ 60 วิ, บุคลิกน้องมะลิ

AI
--
- ใช้ API key ในไฟล์ ../api.txt (Groq) — ไม่ต้องแก้โค้ด
- คุย: openai/gpt-oss-120b   แปลงเสียงพูดเป็นข้อความ: whisper-large-v3   เสียงพูด: gTTS (เหมือนตัวจริง)
- พิมพ์หรือพูดสั่งได้ เช่น "หันซ้ายหน่อย", "เงยหน้าแล้วผงกหัว", "ส่ายหน้าให้ดูหน่อย"
  AI จะตอบเป็นคำพูด + คำสั่งท่าทาง แล้วแปลงเป็นคำสั่ง Serial ชุดเดียวกับที่ ESP32 จริงรับได้

แท็บต่างๆ
---------
💬 คุยกับ AI   : แชท, ปุ่มไมค์ (หยุดเองเมื่อเงียบ), โหมดฟังต่อเนื่อง
🎮 ควบคุม      : ปุ่ม NOD/TILT/THINK/I, สไลเดอร์ Pan/Tilt/Eye, แผงลากกลอกตา, พิมพ์คำสั่ง Serial เอง, ทดสอบปาก
📷 กล้อง/ลูกค้า : เปิดกล้องคอมจริงอัตโนมัติ (เว็บแคมผ่าน OpenCV) หุ่นจะหันตาม/ทักทายจากใบหน้าจริง
                 ถ้าเปิดไม่ได้ เลือกหมายเลขกล้องแล้วกด "↻ เปิดกล้องใหม่"
                 (ใช้ Haar cascade แบบ robot_brain.py ถ้า OpenCV มี, ถ้าเป็น OpenCV 5 จะใช้ YuNet ใน models/ แทน)
                 ต้องปิด robot_brain.py ก่อน เพราะใช้กล้องตัวเดียวกัน
⚙️ ตั้งค่า      : REVERSE_PAN/TILT/EYE, FACE_CLOSE_THRESHOLD, ความไวไมค์, ต่อหุ่นจริงผ่าน COM port

ต่อหุ่นจริง: ปิด robot_brain.py ก่อน (ใช้ COM พอร์ตเดียวกัน) แล้วเลือกพอร์ตในแท็บตั้งค่า -> เชื่อมต่อ
ทุกคำสั่งที่เห็นใน Serial Monitor จะถูกส่งไป ESP32-S3 จริงด้วย

ข้อมูลอ้างอิง (โฟลเดอร์ ../information)
--------------------------------------
ใส่ไฟล์ .txt .md .csv .json .docx .pdf -> น้องมะลิอ่านก่อนตอบทุกครั้ง (เพิ่ม/แก้ไฟล์แล้วใช้ได้ทันที)
ไฟล์ที่ขึ้นต้นด้วย _ จะถูกข้าม ดูวิธีเขียนใน information/_วิธีใช้โฟลเดอร์นี้.txt
ใต้คำตอบในแชทจะบอกว่าอ้างอิงจากไฟล์ไหน / แท็บตั้งค่ามีรายการไฟล์ + ปุ่มเปิดโฟลเดอร์

การฟังเสียง
-----------
ไมค์จะส่งเสียงไปแปลงก็ต่อเมื่อมีเสียงพูดจริง (ย่านความถี่เสียงคน, ยาว >= 0.35 วิ, ปรับตามเสียงรบกวนในห้องเอง)
และกรองคำที่ Whisper ชอบแต่งเองตอนเงียบ เช่น "สวัสดีครับ", "ขอบคุณที่รับชม", "โปรดติดตามตอนต่อไป"
สถานะการฟังแสดงใต้ช่องพิมพ์ในแท็บแชท

กล้องคอมจริง: หุ่นมองเฉพาะคนที่อยู่ใกล้กล้องที่สุด (กรอบหนา 🎯) คนอื่นเป็นกรอบเส้นประ
จะเปลี่ยนไปมองคนอื่นก็ต่อเมื่อคนนั้นเข้ามาใกล้กว่าอย่างชัดเจนสักครู่
